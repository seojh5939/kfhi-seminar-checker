## 1. 개요 및 요구사항 분석

v1.1 버전에서는 기존 고정된 엑셀 포맷 및 관리번호 중심의 구조에서 탈피하여, **동적 엑셀 헤더 인식**, **사모님 참석자 자동 분리/생성**, **티셔츠 사이즈 필드 추가**, **새로운 파일명 규칙**, **QR 데이터 경량화 및 인식률 최적화**를 달성합니다.

### 1.1 요구사항 요약
1. **엑셀 시트 최상단 Header 동적 인식**: 하드코딩된 열 매핑이 아닌, 엑셀 1행의 실제 컬럼 헤더들을 자동 탐지.
2. **고유 일련번호(관리번호) 제거 및 파일명 규칙 개편**:
   - 기존: `00001.png`
   - 변경: `이사회명_직책_성명.png` (예: `서울후원이사회_회장_홍길동.png`, `경기후원이사회_사모_김영희.png`)
3. **사모님 참석자 자동 감지 및 분리 생성**:
   - 엑셀 행에 '사모님 성함' 열이 존재하고 값이 기재되어 있는 경우, 해당 행에서 **본인 QR**과 **사모님 QR(직함: '사모')** 2건을 분리 생성.
   - 사모님 성함, 사모님 티셔츠 사이즈를 추출하여 각각 독립된 QR 이미지 및 매니페스트 레코드로 생성.
4. **티셔츠(T셔츠) 사이즈 필드 추가**: 본인 및 사모님 정보에 티셔츠 사이즈 항목을 포함.
5. **헤더 매핑(Header Mapping) UI 단계 신설**: 인식된 헤더 중 이사회명, 직책, 성명, 티셔츠사이즈, 사모님성함, 사모님티셔츠 등을 사용자가 지정/확인할 수 있는 UI 플로우 추가.
6. **QR 암호화 길이 및 인식률 검토**: 데이터 증가에 따른 QR 코드 밀도 증가 우려 해소 및 암호화/평문 최적화 방안 수립.

## 2. 세부 항목별 기술 분석 및 설계

### 2.1 [요구사항 1 & 5] 동적 헤더 인식 및 컬럼 매핑 UI 플로우

#### A. 동적 헤더 인식 (ExcelParser 개선)
- 엑셀 파일 로드 시 1행의 모든 유효 셀을 순회하여 `headers: string[]` 및 샘플 데이터(상위 3~5행)를 추출하여 반환.
- 유사 키워드 정규식 기반 **스마트 자동 매칭(Smart Auto-Matching)** 알고리즘 적용:
  - **이사회명(소속)**: `/이사회|소속|지부|지회/`
  - **직책(직함)**: `/직책|직함|직분/`
  - **성명(본인)**: `/^(?!.*사모).*(성명|이름|참석자)/` (사모님 제외)
  - **티셔츠 사이즈(본인)**: `/^(?!.*사모).*(티셔츠|t셔츠|상의|사이즈|size)/i` (사모님 제외)
  - **사모님 성함**: `/사모.*(성명|이름)|사모님/`
  - **사모님 티셔츠 사이즈**: `/사모.*(티셔츠|t셔츠|사이즈|size)/i`

#### B. 생성기 UI 플로우 (Step 전환 구조)
- **Step 1 (엑셀 업로드)**: 엑셀 파일 드롭/선택 ➡️ 헤더 목록 파싱.
- **Step 2 (헤더 매핑 - 신설)**: 
  - 감지된 헤더 목록 표시.
  - 드롭다운 셀렉트를 통해 각 표준 필드(이사회명, 직책, 이름, 티셔츠, 사모님성함, 사모님티셔츠)와 매핑.
  - 스마트 매칭으로 기본값이 자동 세팅되어 사용자는 필요 시 조정 후 "다음 단계" 진행.
- **Step 3 (미리보기 및 폴더 지정)**: 
  - 파싱 결과 미리보기 테이블 (본인 + 사모님 분리된 총 생성 대상 N건 확인).
  - 저장 폴더 선택.
- **Step 4 & 5 (생성 진행 및 완료)**: 일괄 생성 및 완료 화면.

### 2.2 [요구사항 2] 일련번호 제거 및 파일명 규칙 개편

#### A. 파일명 규칙
- **표준 파일명 포맷**: `${affiliation}_${title}_${name}.png`
- **예시**:
  - 본인: `서울후원이사회_회장_홍길동.png`
  - 사모님: `서울후원이사회_사모_김영희.png`
- **파일명 안전 처리(Sanitization)**:
  - Windows 파일 시스템에서 허용되지 않는 특수문자(`\ / : * ? " < > |`)는 `_`로 치환 처리.
  - 공백 문자는 제거 또는 언더스코어로 정리.

#### B. 고유 식별자(ID) 대체 방안 (Reader 및 중복 방지)
- 관리번호(`00001`)가 없어지므로, 시스템 내부 Unique Key로 **`이사회명_직책_성명`** 을 조합하여 활용.
- InDesign Data Merge용 TXT 매니페스트에도 `#QR코드` 필드에 해당 파일명(`이사회명_직책_성명.png`)이 기록됨.

### 2.3 [요구사항 3 & 4] 사모님 분리 생성 및 티셔츠 사이즈 추가

#### A. 데이터 모델 확장 (`shared/src/types/index.ts`)
```typescript
export interface AttendeeInput {
  affiliation: string;    // 이사회명 (예: "서울후원이사회")
  title: string;          // 직책 (본인은 "회장", "총무" 등, 사모님은 "사모")
  name: string;           // 성명
  tshirtSize?: string;    // 티셔츠 사이즈 (예: "100", "XL", "L", "95" 등, 공란 허용)
  isSpouse?: boolean;     // 사모님 여부
}

export interface QRPayload {
  v: number;              // 규격 버전 (2)
  a: string;              // 이사회명 (affiliation)
  t: string;              // 직책 (title)
  n: string;              // 성명 (name)
  s?: string;             // 티셔츠 사이즈 (size)
  ts: number;             // 생성 시각 (ms)
}
```

#### B. 엑셀 행 분리 로직 (1행 ➡️ 최대 2건의 Attendee 생성)
1. **본인 레코드 생성**:
   - `affiliation`: 엑셀 이사회명
   - `title`: 엑셀 직책
   - `name`: 엑셀 본인 성명
   - `tshirtSize`: 엑셀 본인 티셔츠사이즈
2. **사모님 레코드 생성 (조건부)**:
   - 엑셀의 '사모님 성함' 열에 값이 존재하는 경우 (`spouseName.trim() !== ''`):
     - `affiliation`: 엑셀 이사회명 (동일)
     - `title`: `'사모'` (고정)
     - `name`: 엑셀 사모님 성함
     - `tshirtSize`: 엑셀 사모님 티셔츠사이즈
     - `isSpouse`: `true`
   - 사모님 성함이 비어있으면 사모님 레코드는 생성하지 않음.

### 2.4 [요구사항 6] QR 데이터 길이 및 인식률 기술 검토

#### A. 데이터 포맷별 길이 및 QR 셀 밀도 비교

| 방식 | 페이로드 예시 | 데이터 길이 | QR 버전 (ECC Level M) | 모듈 크기 및 인식 속도 |
| :--- | :--- | :--- | :--- | :--- |
| **1. 초경량 평문 (Plaintext)** | `v2\|서울후원이사회\|회장\|홍길동\|100` | 약 **38 바이트** | **Version 3** (29×29 셀) | **초고속 (0.03초)** / 셀이 매우 큼 |
| **2. 콤팩트 AES-256-GCM** | `IV(12B) + Tag(16B) + Cipher(38B)` Base64URL | 약 **88 자 (ASCII)** | **Version 5** (37×37 셀) | **매우 빠름 (0.05초)** / 충분히 큼 |
| **3. 기존 JSON AES-256-GCM (Hex)** | `IV:Tag:Cipher` Hex 포맷 | 약 **210 자** | **Version 10** (57×57 셀) | 보통 (0.1~0.2초) / 셀이 촘촘함 |

#### B. 권장 아키텍처: "하이브리드 자동 감지 (Auto-Detect) 아키텍처"
1. **QR 생성기 (Generator)**:
   - 기본적으로 **초경량 평문 모드** 또는 **경량 암호화 모드**를 옵션 토글(`[ ] QR 데이터 암호화 적용`)로 제공.
   - 평문 포맷: `v2|이사회명|직책|이름|티셔츠사이즈` (티셔츠 사이즈가 추가되어도 38자 수준으로 QR 셀이 매우 큼)
2. **QR 인식기 (Reader)**:
   - 수신된 문자열이 `v2|...` 또는 `v1|...` 로 시작하면 **즉시 평문 파싱 (0ms)**
   - 그 외 암호문인 경우 **AES-256-GCM 복호화 후 파싱**
   - **효과**: 생성기에서 암호화를 켜든 끄든, 인식기는 100% 아무런 설정 없이 모두 즉시 스캔 가능!

## 3. InDesign Data Merge 매니페스트 호환성

- v1.1 변경 매니페스트 규격 (`manifest.txt`, UTF-16 LE with BOM):
  `이사회명\t직함\t성명\t티셔츠사이즈\t#QR코드`
- 행 데이터 예시:
  ```tsv
  이사회명	직함	성명	티셔츠사이즈	#QR코드
  서울후원이사회	회장	홍길동	100	서울후원이사회_회장_홍길동.png
  서울후원이사회	사모	김영희	95	서울후원이사회_사모_김영희.png
  경기후원이사회	총무	이순신	105	경기후원이사회_총무_이순신.png
  ```
- Adobe InDesign Data Merge(데이터 병합)에서 한글 깨짐 없이 텍스트 및 이미지 프레임(`#QR코드`)과 100% 매핑됩니다.
